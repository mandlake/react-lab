# ⚡ React `useTransition` 성능 최적화 테스트

간단한 테스트들을 위한 페이지입니다.  
React 18 동시성 기능(Concurrent Feature)의 핵심인 `useTransition`을 활용해 우선순위 기반 렌더링을 검증합니다.

---

## 🎯 테스트 목적

- **긴급 vs 비긴급 상태 분리:** 사용자 입력(타이핑)은 즉각 반영하고, 무거운 리스트 렌더링은 백그라운드로 지연 처리
- **메인 스레드 블로킹 방지:** 렌더링 중에도 사용자 인터럽트(입력)를 우선 수신하는지 확인
- **`isPending` 기반 UX:** 전체 스피너 대신 기존 UI 투명도 조절을 통한 부드러운 전환 구현

---

## 🧪 테스트 방법

1. `/TransitionTest` 페이지로 이동합니다.
2. 검색창에 글자를 빠르게 연속으로 입력합니다.
3. 입력창 텍스트는 즉시 반응하고, 하단 리스트는 비동기로 갱신되며 반투명(0.6) 처리되는지 확인합니다.
4. `startTransition`을 풀었을 때 인풋 창이 버벅거리는 현상과 비교합니다.

---

## 📌 핵심 비교

- **Debounce:** 일정 시간 동안 실행을 **강제 지연** (API 요청 횟수 감소 목적)
- **useTransition:** CPU 여유 시 **즉시 백그라운드 렌더링**, 새 입력 발생 시에만 작업 양보 (DOM 렌더링 최적화 목적)
