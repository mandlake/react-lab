# ⚡ React `useOptimistic` 선언적 예측 상태 테스트

간단한 테스트들을 위한 페이지입니다.  
React 19의 `useOptimistic` 훅을 활용하여 비동기 네트워크 통신 지연 중에도 사용자 반응성을 극대화하고, 실패 시 별도의 수동 원복 코드 없이 원본 상태로 자동 롤백되는 패턴을 검증합니다.

---

## 🎯 테스트 목적

- **낙관적 업데이트(Optimistic Update):** API 요청 응답을 기다리지 않고 즉각 UI를 갱신하여 쾌적한 UX 제공.
- **선언적 자동 롤백(Declarative Rollback):** API 실패 시 복잡한 원상 복구(`setCount(prev - 1)`) 로직 없이, React가 비동기 액션 종료 시 원본 상태(`serverLikes`)로 자동 동기화하는 구조 확인.

---

## 🧪 테스트 방법

1. `/optimisticTest` 페이지로 이동합니다.
2. **성공 케이스:**
   - '좋아요 누르기' 클릭 즉시 숫자가 +1로 올라가고, 1.5초 뒤 실제 서버 상태도 갱신됩니다.
3. **실패 케이스:**
   - '서버 API 요청 실패 시뮬레이션' 체크박스를 체크한 후 '좋아요 누르기'를 클릭합니다.
   - 클릭 즉시 숫자가 +1로 올랐다가, 1.5초 후 요청 실패와 동시에 **원래 숫자로 자동 롤백**되는 현상을 확인합니다.
